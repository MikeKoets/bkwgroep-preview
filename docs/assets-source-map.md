# BKW Groep assetbron

Alle assets in `public/assets` zijn op 10 oktober 2026 verkregen van de publiek toegankelijke huidige website van BKW Groep. De eigenaar heeft in de opdracht expliciet toestemming gegeven om bestaande merkassets en fotografie in deze preview te hergebruiken.

| Previewbestand | Oorspronkelijke vindplaats | Gebruik |
| --- | --- | --- |
| `logo-bkw.svg` | Publieke stylesheet op `https://bkwgroep.nl/` | Officieel BKW-beeldmerk |
| `images/home-hero.webp` | Homepage `https://bkwgroep.nl/` | Teamexterieur en bedrijfsvoertuigen |
| `images/professionals.webp` | Homepage `https://bkwgroep.nl/` | Onderhoudswerk in uitvoering |
| `images/maintenance-hero.webp` | `https://bkwgroep.nl/onderhoud/` | Onderhoudsbezoek bij woning |
| `images/locks-hero.webp` | `https://bkwgroep.nl/slotenservice/` | Slotenwerk aan deur |
| `images/business.webp` | `https://bkwgroep.nl/zakelijk/` | Zakelijk vastgoed |
| `images/contact.webp` | `https://bkwgroep.nl/contact/` | Isolatiewerk |

De rasterbestanden zijn uitsluitend verkleind en naar WebP omgezet. Er zijn geen gegenereerde projectbeelden toegevoegd.
